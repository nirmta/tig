# Installation Guide

This guide covers all methods to install **TIG** on Linux and macOS, binary paths generated by GoReleaser, Homebrew tap installation, Debian packages, and PATH setup.

---

## 1. Prerequisites

Before using TIG, ensure that **Git** and **OpenSSH client** are installed on your workstation.

### On Debian / Ubuntu:
```bash
sudo apt update
sudo apt install -y git openssh-client
```

### On macOS (Homebrew):
```bash
brew install git openssh
```

---

## 2. Supported Platforms & Architectures

TIG provides pre-compiled binaries and packages for Linux, macOS, and Windows across `amd64` and `arm64` architectures:

| Platform | Architecture | Archive / Package | Target Install Path |
| :--- | :--- | :--- | :--- |
| **macOS (Darwin)** | Apple Silicon (`arm64`) | `tig_Darwin_arm64.tar.gz` | `/usr/local/bin/tig` |
| **macOS (Darwin)** | Intel (`x86_64`) | `tig_Darwin_x86_64.tar.gz` | `/usr/local/bin/tig` |
| **Linux** | 64-bit x86 (`x86_64`) | `tig_Linux_x86_64.tar.gz` | `/usr/local/bin/tig` |
| **Linux** | ARM64 (`arm64`) | `tig_Linux_arm64.tar.gz` | `/usr/local/bin/tig` |
| **Debian / Ubuntu** | `.deb` Package | `tig_linux_amd64.deb` / `arm64.deb` | `/usr/bin/tig` |
| **Windows** | x86_64 / arm64 | `tig_Windows_x86_64.zip` | `%USERPROFILE%\bin\tig.exe` |

---

## 3. macOS Installation (Homebrew Tap)

TIG provides a dedicated Homebrew tap (`nirmta/homebrew-tig`):

```bash
# Add tap and install
brew tap nirmta/tig
brew install tig
```

The binary will be linked to:
- **Apple Silicon (M1/M2/M3/M4)**: `/opt/homebrew/bin/tig`
- **Intel Macs**: `/usr/local/bin/tig`

---

## 4. Linux Installation (Debian / Ubuntu `.deb`)

GoReleaser produces `.deb` packages using `nfpm` that install the binary directly into `/usr/bin`:

```bash
# Download and install deb package (replace with target version and architecture)
wget https://github.com/nirmta/tig/releases/latest/download/tig_linux_amd64.deb
sudo dpkg -i tig_linux_amd64.deb
```

---

## 5. Manual Binary Installation (Linux & macOS)

Download the pre-compiled GoReleaser archive for your operating system and architecture:

### On macOS:
```bash
# Detect architecture (arm64 or x86_64) and download
ARCH=$(uname -m)
curl -LO "https://github.com/nirmta/tig/releases/latest/download/tig_Darwin_${ARCH}.tar.gz"

# Extract
tar -xzf "tig_Darwin_${ARCH}.tar.gz"

# Move binary into system PATH
sudo mv tig /usr/local/bin/
sudo chmod +x /usr/local/bin/tig
```

### On Linux:
```bash
# Detect architecture
ARCH=$(uname -m)
curl -LO "https://github.com/nirmta/tig/releases/latest/download/tig_Linux_${ARCH}.tar.gz"

# Extract
tar -xzf "tig_Linux_${ARCH}.tar.gz"

# Move binary into system PATH
sudo mv tig /usr/local/bin/
sudo chmod +x /usr/local/bin/tig
```

---

## 6. Configuring Your PATH

If you install TIG into a user directory (such as `~/.local/bin` or `$GOPATH/bin`), make sure the directory is added to your shell's `PATH`.

### For Zsh (`~/.zshrc` on macOS and modern Linux):
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

### For Bash (`~/.bashrc` or `~/.bash_profile`):
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### For Go CLI Install (`go install`):
```bash
export PATH=$PATH:$(go env GOPATH)/bin
```

---

## 7. Verification

Verify the installation and path resolution:

```bash
which tig
tig --help
```
